# Keybindings

| Shortcut | Action |
|---|---|
| `Super + Enter` | Open Kitty with the buchhwin profile |
| `Super + D` | Open application launcher |
| `Super + B` | Open Brave browser |
| `Super + E` | Open Files (Dolphin) |
| `Super + C` | Open Visual Studio Code |
| `Super + Shift + C` | Toggle Control Center |
| `Super + S` | Region screenshot |
| `Super + Shift + S` | Open system settings |
| `Super + V` | Search clipboard history and copy an older item |
| `Super + N` | Toggle notification center |
| `Super + M` | Open power menu |
| `Super + L` | Lock the session |
| `Super + F1` | Show keybind viewer |
| `Super + Q` | Close focused window |
| `Super + J / K` | Focus next / previous window |
| `Super + Left / Right` | Shrink / grow master area |
| `Super + Up / Down` | Use top/bottom layout and move its divider |
| `Super + I` | Increase number of master windows |
| `Super + Shift + I` | Decrease number of master windows |
| `Super + Shift + Enter` | Promote focused window to master |
| `Super + T` | Tiled layout |
| `Super + F` | Floating layout |
| `Super + Shift + M` | Monocle layout |
| `Super + Space` | Cycle layout |
| `Super + Alt + Space` | Switch side-by-side / top-and-bottom tiling |
| `Super + Shift + Space` | Toggle focused window floating |
| `Super + Shift + F` | Fullscreen |
| `Super + 1..9` | Switch tag |
| `Super + Shift + 1..9` | Move focused window to tag |
| `Super + Ctrl + 1..9` | Toggle tag visibility |
| `Super + , / .` | Focus monitor left / right |
| `Super + Shift + , / .` | Move window to monitor left / right |
| `Super + Print` | Region screenshot |
| `Super + Shift + Print` | Full-screen screenshot |
| `Super + Ctrl + Print` | Region screenshot in Swappy |
| `Super + Shift + Q` | Exit dwl-buchhwin |

Media and brightness hardware keys are supported through `wpctl`, `playerctl`, and `brightnessctl`.

Clipboard history is stored locally by `cliphist`. Open it with `Super+V`; use
the **Clear history** button when copied sensitive data should be removed.
