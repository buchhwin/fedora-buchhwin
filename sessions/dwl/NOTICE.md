# Notice and credits

**fedora-dwl** is an independent Wayland desktop configuration for Fedora 44
with KDE Plasma as its required system foundation and fallback desktop.

It uses the upstream [dwl](https://codeberg.org/dwl/dwl) compositor and the
[Quickshell](https://quickshell.org/) desktop-shell toolkit. The installer
retrieves pinned dwl and SceneFX sources from their upstream repositories and
applies this project's local transformations; their source is not vendored.

The compact keyboard-first workflow and parts of the visual direction were
inspired by ChrisTitusTech's `dwm-titus` project. This repository does not use
that project's branding and does not vendor its source code.
