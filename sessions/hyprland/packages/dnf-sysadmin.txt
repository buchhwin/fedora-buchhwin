# What the session itself needs, and nothing else.
#
# WARNING: THIS LIST HELD 38 PACKAGES AND NOW HOLDS FIVE, and the cut was a
# decision rather than an oversight. It had grown into a personal toolbox —
# nmap, tcpdump, podman, gh, fzf, atuin, keepassxc, remmina, strace, iotop and
# two dozen more — none of which the desktop reads, writes or launches.
#
# The rule now is the one the dwl session has always followed: this repository
# installs a SESSION, not a workstation. Anything you would install anyway,
# install anyway. `dnf install ripgrep` is one line and it is yours, not the
# desktop's, and an installer that picks your CLI tools for you is one you end
# up arguing with.
#
# WARNING: WHAT IS LEFT IS LEFT BECAUSE SOMETHING BREAKS WITHOUT IT. Each line
# names the file that calls it. A line that loses its caller leaves too.
#
# Installed WITH weak dependencies: these are ordinary tools, not the desktop,
# and their recommendations are not a second bar or a second launcher.

zsh-autosuggestions         # dotfiles/zsh/zshrc sources it by path
zsh-syntax-highlighting     # same

playerctl                   # the media keys: config/hypr/buchhwin/binds.lua
rclone                      # shell/services/Drive.qml — the only backend it has
pciutils                    # lspci, read by services/SystemInfo.qml and Connectors.qml
