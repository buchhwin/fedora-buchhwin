# The NVIDIA branch. Installed ONLY when lib/10-gpu.sh finds a real NVIDIA GPU,
# and from RPM Fusion nonfree, which the same phase enables.
#
# ⚠️ THE DESKTOP DOES NOT DEPEND ON ANY OF THIS. The target machine is a hybrid
# laptop — an AMD APU with its integrated Radeon, plus an NVIDIA card — and niri draws on
# the 780M, whose amdgpu driver is in the kernel and needs no signature. If
# every line below fails to install, the desktop still comes up. That is why
# nothing in phase_gpu is allowed to `die`, and why the Secure Boot card in the
# settings window says so in as many words.
#
# What the dGPU is actually for here: on most hybrid laptops the external
# display connectors are wired to it. niri renders on the iGPU and copies
# across, which costs frames on that screen — see niri's own FAQ.md:43-55 and
# the `gpu.renderDevice` setting, which writes `debug { render-drm-device }`.

akmod-nvidia                # the module source; pulls xorg-x11-drv-nvidia with it

# ⚠️ IT IS A LAPTOP, so the suspend/resume units are not optional. Without them
# the dGPU state is not saved across a suspend and the machine can come back to
# a black screen — which on a laptop is the single most common way to meet this
# driver.
xorg-x11-drv-nvidia-power

# Reads and writes the Secure Boot state. `--sb-state`, `--test-key` and
# `--list-new` all answer as an ordinary user, which is what lets both
# `bhctl doctor` and the shell tell the truth without asking for a password.
mokutil

# ⚠️ xorg-x11-drv-nvidia-cuda IS DELIBERATELY ABSENT. It is roughly a gigabyte
# and the only thing it buys this setup is `nvidia-smi`. His decision on
# 07.08.2026 was no CUDA. The instrument used instead costs nothing and is
# provided by the module itself: /proc/driver/nvidia/version.
#
# ⚠️ AND THERE IS NO OFFLOAD WRAPPER, also his decision. Running one chosen
# program on the dGPU (__NV_PRIME_RENDER_OFFLOAD=1) is therefore not reachable —
# stated here rather than left to be discovered, because the packages above make
# it look as though it should be.
